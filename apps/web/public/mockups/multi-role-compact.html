Multi-role rendering — Approach 4: compact rows

Each sub-role still renders as its own row, but the rows are smaller (~30px tall instead of 61px). Per-row content is single-line: short label chip + concise descriptor. Trades visual weight per row for fitting more roles in a fixed budget.

Pros

• Preserves enumeration — every sub-role gets its own descriptor line.
• Predictable height: 30px per role + 4px gap. 4 roles = 132px, 8 roles = 268px.
• Per-row hover/highlight semantics still work (each row is its own focus target).

Cons

• Descriptions truncate to single line — no room to explain mechanics in detail.
• At 8 sub-roles, total height (~268px) still exceeds a single AbilityRow (61px) significantly.
• Smaller font (11px) compared to standard ability rows (13px) — readability shift.
