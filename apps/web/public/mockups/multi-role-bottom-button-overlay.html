Multi-role rendering — In-place overlay expansion

For a single rule with multiple sub-roles (e.g. Location Control with Payoff + Move + Buff), desktop shows only the highest-scoring role's row + a button to reveal the rest. Click the button → the additional roles overlay the area below (they don't push content down). The whole stack reads as one continuous Lorcana ability card.

Decisions baked in

• Visible row uses the role chip; engine's LOCATION_ROLE_CHIP_LABELS short forms (Payoff/Trigger/Buff/Ramp/Move/Check/Search/Boost).
• Top role = engine's first connection (highest score).
• Trigger: button only.
• Open: click button. Toggle: click again or press Esc. Chevron rotates 180° to signal state.
• Layout: expansion is absolute-positioned — engine column doesn't grow; the expanded rows overlay whatever sits below the modal column.
• Visible row has square top corners (per design); rounded bottom when collapsed, square bottom when expanded.
• Mobile: stack-all, no button (no equal-height constraint).

Mobile — stack-all, no button

Payoff Gets bonuses when characters are at the location.
Move Moves characters to the location for an advantage.
Buff Strengthens the location with Resist or stat boosts.

Mobile lays columns vertically (one above the other), so engine column height isn't constrained. All roles render in full.

Edge cases

1 role: renders as a normal AbilityRow with no button (today's behavior, unchanged).
2 roles: top row + button; expansion reveals the second.
5+ roles: button stays the same shape; the overlay extension grows downward and may overflow the modal — internal scroll on the overlay-extension solves this.
Connection group has 1 rule (multi-rule case): not affected by this — we agreed that's a separate decision (selection rule, not display rule).

React shape

New component MultiRoleAbilityList wrapping the existing AbilityRow. ConnectionGroup.tsx swaps its current multipleRoles ? stack : single branch to route through the list. The list owns its useState for open/closed. The expansion is absolute-positioned, so the engine column's intrinsic height is unchanged — equal-height column work isn't disturbed by expansion. Mobile (via the existing breakpoint hook) skips the toggle entirely and renders all roles always-open.
