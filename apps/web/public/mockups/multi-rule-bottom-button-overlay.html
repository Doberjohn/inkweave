Multi-rule rendering — Bottom-center button + in-place overlay

The visible state shows only the top rule. A small circular button straddles the bottom-center of the row's border (half above, half below). A small "+N" badge in the button's top-right corner names the count of hidden rules. Clicking the button opens an overlay that occupies the same engine-column area, listing all rules.

Pros

• Adds only ~14px of vertical space (button protrudes below row).
• Strong affordance — circular button is universally read as interactive.
• "+N" badge gives precise count without taking sentence-space.
• Overlay is contained to the engine column, doesn't shift the modal layout when opened.

Cons

• Overlay temporarily hides the visible top rule (user has to dismiss to see it again).
• Two-step interaction (click button → review overlay → close).
• The protruding button creates a small visual "knob" at every connection group, which could feel busy if multiple groups exist.
